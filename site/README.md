# miaomiao-site

## What this is

A single-page marketing site plus four JSON endpoints, running as a Cloudflare Worker
with Static Assets. Everything that can be static is static, so the site costs
almost nothing to host.

| Route | Handler | Purpose |
| --- | --- | --- |
| `/` | Static asset | Landing page (Chinese by default, English toggle) |
| `/api/release` | Worker | Latest version manifest from R2 |
| `/api/download?arch=arm64\|x64` | Worker | Streams the dmg from R2, supports `Range` |
| `/api/ping` | Worker | One anonymous launch row from the app (random device id + coarse geo) |
| `/api/stats` | Worker | Aggregated device counts, cities and daily UV — never device ids |

## Privacy

This site deliberately has no third-party anything:

- no analytics, no ads, no cookies, no external fonts or CDNs
- the worker writes standard Workers Logs (3 day retention) for debugging; it never stores IPs in D1
- the only state is a 60 second in-memory cache of the release manifest, plus anonymous
  launch counts in D1: a random device id generated by the app, the UTC date, and the
  coarse geo Cloudflare derives from the request (no IP, no user agent, no hardware id)

## Local development

```bash
npm install
npx wrangler dev --port 8799
```

The worker binds a local R2 bucket automatically. To try the download flow:

```bash
# create a manifest and push a build into the local bucket
# (the shared `common` bucket, with this project's `miaomiao-notes/` prefix)
npx wrangler r2 object put "common/miaomiao-notes/releases/latest.json" --file=latest.json --local
npx wrangler r2 object put "common/miaomiao-notes/releases/miaomiao-notes-1.2.1-arm64.dmg" --file=path/to.dmg --local
```

## Release manifest

`releases/latest.json` in the R2 bucket describes the current build. Only the
latest version is served; uploading a new one replaces the manifest.

```json
{
  "version": "1.2.1",
  "released_at": "2026-10-20",
  "files": {
    "arm64": { "key": "releases/miaomiao-notes-1.2.1-arm64.dmg", "name": "miaomiao-notes-1.2.1-arm64.dmg", "size": 103825402 },
    "x64":   { "key": "releases/miaomiao-notes-1.2.1-x64.dmg",   "name": "miaomiao-notes-1.2.1-x64.dmg",   "size": 111126987 }
  }
}
```

## Deploy

```bash
# shipping worker / static asset changes
npm run deploy

# shipping a new app version (dmgs + manifest, no worker deploy needed)
cd .. && npm run dist
cd site && npm run release
```

`npm run release` uploads both dmgs from `../release` into the `miaomiao` bucket
and rewrites `latest.json`, so the site and the in-app update check pick the new
version up within the 60 second manifest cache. It then **deletes the dmgs the
previous manifest pointed at**, so the bucket only ever holds the live version —
the order is deliberate: prune runs only after the new manifest is in place, so
no client can ever resolve to a file that has already been removed. The bucket is
the shared `common` bucket (created once by hand, reused by every project on the
account; this one only writes under the `miaomiao-notes/` prefix), and is already
declared as the `R2_RELEASES` binding in `wrangler.jsonc`.

The custom domain `notes.wordtk.com` is declared in `wrangler.jsonc`; wrangler
creates the DNS record and certificate on first deploy.

The D1 database is the **shared `common` database** — the free plan allows 10 databases and
this site only keeps launch counts, so sendtk, codetk, miaomiao-bar and this site live in the
same one. The table is `notes_launches` and its indexes are `idx_notes_launches_*`; first-time
setup (or a fresh clone) is:

```bash
npx wrangler d1 migrations apply common --remote   # --local for the dev database
```

Because `common` is shared, `d1_migrations` is a database-wide ledger **keyed by file name**.
Every file in `migrations/` therefore keeps its project prefix (`0001_notes_init.sql`) —
a plain `0001_init.sql` would collide with a migration another project already recorded and
be skipped silently.

## Project layout

```
src/index.js        Worker: /api/release, /api/download, /api/ping, /api/stats
public/             Static assets served without invoking the worker
  index.html        Landing page
  styles.css        Single light theme
  app.js            Language toggle + release metadata
  assets/           Icon and screenshot
migrations/         D1 schema — 0001_notes_init.sql creates notes_launches
wrangler.jsonc      Worker config (assets, R2 binding, shared D1, custom domain)
```
